Problem 14 — The transition at eccentricity one

Damian Chorążkiewicz

← Exercise set 04 Lecture 04

Task

Fix \(p=2\) and consider the family

\[ r_e(\theta)=\frac{2}{1+e\cos\theta} \]

for \(e=0.5,0.9,1,1.1,1.5\).

  1. Compute \(r_e(0)\) for all five values of \(e\).
  2. Compute \(r_e(\pi)\) whenever it is finite and nonnegative under the convention \(r\ge0\).
  3. For \(e>1\), find the angles at which the denominator is zero.
  4. Produce five comparable sketches, using the same coordinate scale whenever possible.
  5. Describe what changes as \(e\) approaches \(1\) from below and what changes after \(e\) exceeds \(1\).

Required record

Include one numerical table, five sketches and a comparison of the cases below, at and above \(e=1\).

Verification

The sketches must agree with the calculated radius at \(\theta=0\) and with the denominator analysis near \(\theta=\pi\).
