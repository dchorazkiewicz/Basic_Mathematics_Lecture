Problem 13 — From parametrization to Cartesian equation

Damian Chorążkiewicz

← Exercise set 04 Lecture 04

Task

Study the two parametrizations

\[ P(t)=(2\cos t,3\sin t) \]

and

\[ Q(s)=(s,s^2-2). \]
  1. Eliminate the parameter from each description and obtain a Cartesian equation.
  2. State the parameter interval needed for \(P\) to trace its curve exactly once.
  3. Decide whether any finite interval of \(s\) traces the complete Cartesian curve of \(Q\).
  4. Verify three generated points in each Cartesian equation.
  5. Explain what may be lost when a parametrization is replaced by a Cartesian equation.

Required record

Include both eliminations, the interval discussion, six checks and a comparison paragraph.

Verification

Distinguish carefully between proving that every generated point lies on a Cartesian curve and proving that every point of that curve is generated.
