Problem 05 — Reading centres and semiaxes

Damian Chorążkiewicz

← Exercise set 04 Lecture 04

Task

For each equation, determine the centre, horizontal semiaxis, vertical semiaxis, total width and total height:

\[ \text{A: }\frac{x^2}{9}+\frac{y^2}{4}=1, \]
\[ \text{B: }\frac{(x-2)^2}{9}+\frac{(y+1)^2}{4}=1, \]
\[ \text{C: }\frac{(x+1)^2}{4}+\frac{(y-3)^2}{16}=1. \]
  1. Record the data in one table.
  2. Write the four axis vertices of every ellipse.
  3. Draw the three ellipses in one coordinate system.
  4. Identify which pair differs only by a translation.

Required record

Include the comparison table, all twelve vertices and one labelled coordinate diagram.

Verification

Substitute one vertex into each original equation and check that the left-hand side equals \(1\).
