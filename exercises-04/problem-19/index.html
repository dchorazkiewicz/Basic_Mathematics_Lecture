Problem 19 — Audit of a trajectory model

Damian Chorążkiewicz

← Exercise set 04 Lecture 04

Task

A report about an idealized orbit contains the following statements:

  1. The trajectory satisfies \(\frac{x^2}{16}+\frac{y^2}{9}=1\).
  2. The position is displayed by \(P(t)=(4\cos t,3\sin t)\).
  3. The parameter \(t\) is physical time.
  4. The central body is fixed at one focus.
  5. No third body perturbs the motion.
  6. The trajectory is bounded.
  7. The body moves with constant speed because the curve is an ellipse.
  8. The displayed parametrization follows from Newton's law of gravitation.
  9. The geometric path alone determines the force law.
  10. Changing the parametrization changes the ellipse itself.

For every statement:

  1. classify it as geometric information, parametrization, physical assumption, justified conclusion or unsupported conclusion;
  2. state whether it follows from the preceding data;
  3. correct every unsupported conclusion;
  4. organize the result in a three-level diagram: curve — motion — physical law.

Required record

Include the ten-row audit table, corrected statements and the three-level diagram.

Verification

Give one explicit alternative parametrization of the same ellipse to demonstrate that the geometric path does not determine a unique motion.
