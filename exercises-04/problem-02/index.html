Problem 02 — Points of a parametrized ellipse

Damian Chorążkiewicz

← Exercise set 04 Lecture 04

Task

Let

\[ P(t)=(4\cos t,2\sin t). \]
  1. Compute \(P(t)\) for \(t=0,\frac{\pi}{4},\frac{\pi}{2},\pi,\frac{3\pi}{2}\).
  2. Plot the points and sketch the ellipse.
  3. Verify that every computed point satisfies \(\frac{x^2}{16}+\frac{y^2}{4}=1\).
  4. State the centre, horizontal semiaxis and vertical semiaxis.
  5. Identify the four vertices lying on the coordinate axes.

Required record

Include a parameter table, the labelled sketch, the semiaxes and the substitution checks.

Verification

Use the point corresponding to \(t=\frac{\pi}{4}\) to check the equation with two nonzero coordinates.
