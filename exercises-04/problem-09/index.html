Problem 09 — Classifying radial conics

Damian Chorążkiewicz

← Exercise set 04 Lecture 04

Task

Use the convention \(r\ge0\). For each equation, identify \(p\), identify \(e\), classify the conic and compute \(r(0)\) and \(r(\pi)\) whenever the formula gives a finite nonnegative radius:

\[ \text{A: }r=4, \]
\[ \text{B: }r=\frac{3}{1+0.6\cos\theta}, \]
\[ \text{C: }r=\frac{5}{1+\cos\theta}, \]
\[ \text{D: }r=\frac{2}{1+1.5\cos\theta}. \]
  1. Record the results in one table.
  2. Explain why \(\theta=\pi\) does not produce an admissible radial point in cases C and D. Distinguish a zero denominator from a negative value of \(r\).
  3. Draw a qualitative sketch of each conic or conic branch.

Required record

Include the classification table, the special-angle calculations and four labelled sketches.

Verification

Check the sign of the denominator before accepting a value as a radial distance under the convention \(r\ge0\).
