Problem 20 — A complete conic-model note

Damian Chorążkiewicz

← Exercise set 04 Lecture 04

Task

Consider the radial curve

\[ r(\theta)=\frac{3}{1+0.5\cos\theta}, \]

with the focus at the origin and \(r\ge0\).

Prepare one coherent mathematical note that contains all of the following:

  1. identify \(p\), \(e\) and the conic type;
  2. compute \(r(0)\), \(r(\frac{\pi}{2})\) and \(r(\pi)\) and convert the corresponding points to Cartesian coordinates;
  3. determine the directrix \(x=d\) from \(p=ed\);
  4. verify the focus-directrix ratio at two of the calculated points;
  5. draw the curve, focus, directrix, radial segments and perpendicular distance segments;
  6. explain which information is geometric, which information belongs to the chosen radial representation and which information would still be needed to describe a physical motion;
  7. list two conclusions that cannot be inferred from the conic equation alone.

Required record

Submit one structured note containing calculations, a labelled diagram, the distance-ratio checks and a three-level model table.

Verification

Every labelled point in the diagram must agree with the radial calculation, and both ratio checks must return \(e=0.5\).
