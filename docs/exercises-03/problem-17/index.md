## Task

Use the point $P_0=(1,1,1)$ and the vectors

$$
u=(1,0,1),\qquad v=(0,1,1),\qquad w=(2,0,2).
$$

1. Describe the set generated by $P_0+su$.
2. Describe the set generated by $P_0+su+tv$.
3. Describe the set generated by $P_0+su+tw$.
4. Explain why $u$ and $v$ generate a plane but $u$ and $w$ do not.
5. Generate at least four points from each of the three descriptions.
6. Prepare two or three labelled views showing the dimensional difference between the generated sets.
7. State a practical test for deciding whether two directions generate a plane.

<div class="required-record" markdown>

### Required record

Include three parameter tables, the dependence test and a visual comparison of the generated sets.

</div>

<div class="verification-box" markdown>

### Verification

Show explicitly that $w=2u$ and that $v$ is not a scalar multiple of $u$.

</div>
