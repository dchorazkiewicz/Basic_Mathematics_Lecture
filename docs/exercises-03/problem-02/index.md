## Task

Let $A=(-2,1)$ and $B=(4,4)$.

1. Compute the direction vector $v=B-A$.
2. Write a parametric equation of the line through $A$ and $B$ using $A$ as the initial point.
3. Write another parametric equation using $B$ as the initial point.
4. Find the parameter values corresponding to $A$ and $B$ in both descriptions.
5. Determine whether $C=(2,3)$ belongs to the line.
6. Plot $A$, $B$, $C$ and both direction vectors used in your descriptions.

<div class="required-record" markdown>

### Required record

Include both parametric equations, the membership test for $C$ and one common drawing.

</div>

<div class="verification-box" markdown>

### Verification

Show that both equations generate at least two common points.
