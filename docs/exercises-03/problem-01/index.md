## Task

Let the line be given by

$$
P(t)=(1,2)+t(2,-1).
$$

1. Compute the points corresponding to $t=-2,-1,0,1,2$.
2. Record the results in a table with columns $t$, $x(t)$ and $y(t)$.
3. Plot the five points and draw the line through them.
4. Decide whether $A=(5,0)$ and $B=(4,1)$ belong to the line.
5. For every point that belongs to the line, find the corresponding value of $t$.

<div class="required-record" markdown>

### Required record

Include the parameter table, the drawing and both membership calculations.

</div>

<div class="verification-box" markdown>

### Verification

Substitute two generated points into the coordinate equations $x=1+2t$ and $y=2-t$.

</div>
