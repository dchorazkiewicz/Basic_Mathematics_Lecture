## Task

Start from the line

$$
L:\quad P(t)=(1,2)+t(2,1).
$$

1. Generate the points corresponding to $t=-1,0,1,2$.
2. Choose one generated point different from $(1,2)$ as a new initial point.
3. Write a second parametrization using the direction $(4,2)$.
4. Write a third parametrization using the direction $(-2,-1)$.
5. For each parametrization, find parameter values that generate two common points.
6. Explain how changing the initial point or multiplying the direction vector changes the parameter but not the generated set.
7. Draw the three descriptions on one diagram without drawing three different geometric lines.

<div class="required-record" markdown>

### Required record

Prepare a comparison table containing the initial point, direction vector and parameter values producing the selected common points.

</div>

<div class="verification-box" markdown>

### Verification

Demonstrate equality of the represented sets by matching at least two points and explaining why the direction vectors are nonzero multiples of one another.

</div>
