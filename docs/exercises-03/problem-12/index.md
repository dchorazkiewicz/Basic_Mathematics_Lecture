## Task

Consider the vertical line $L$ through the point $(3,-2)$.

1. Write a parametric equation of $L$.
2. Write a normal equation and an implicit Cartesian equation of $L$.
3. Explain why there is no finite slope $m$ for which $L$ has the form $y=mx+b$.
4. Choose four parameter values and generate four points.
5. Verify all four points in the implicit equation.
6. Compare the information visible immediately in each applicable representation.
7. Prepare a small diagram showing the direction vector, normal vector and the line.

<div class="required-record" markdown>

### Required record

Create a three-column comparison: representation, data visible immediately, and limitation of the representation.

</div>

<div class="verification-box" markdown>

### Verification

Check that the selected direction and normal vectors are perpendicular and that every generated point has first coordinate $3$.

</div>
