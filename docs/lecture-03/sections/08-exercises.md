## Exercises {#exercises}

The companion set contains twenty problems:

- **Problems 01–10** consolidate line generation, equivalent representations, intersections, distance and elementary plane construction;
- **Problems 11–20** require comparison of methods, geometric explanation, spatial visualization and concise mathematical documentation.

[Open Exercise Set 03 →](../../exercises-03/){ .companion-button }

The line remains the primary object. The final problems extend the same ideas to planes without turning the set into a separate catalogue of spatial formulas.
