## Problem

Consider the circle of radius $2$ centred at the origin.

### Description A — relation

$$
x^2+y^2=4.
$$

### Description B — two function branches

$$
y=\sqrt{4-x^2},\qquad y=-\sqrt{4-x^2}.
$$

### Description C — parametrization

$$
x(t)=2\cos t,\qquad y(t)=2\sin t,\qquad 0\le t\le2\pi.
$$

1. State the domain required in Description B.
2. Explain why neither branch in Description B describes the entire circle.
3. Use each description to generate or verify the points
$$
   (2,0),\quad (0,2),\quad (-2,0),\quad (0,-2).
$$
4. Find all points of the circle having first coordinate $x=1$ using Description A or B.
5. Find parameter values generating those points using Description C.
6. Prepare a comparison table with the columns: description, input, output, what part of the circle is covered, principal limitation.
7. Explain why the three descriptions represent the same geometric object even though their formulas and input variables differ.

<div class="required-record" markdown>

### Required record

Include one common diagram, the calculations for $x=1$, the comparison table and a conclusion of four to six sentences.

</div>
