## Task

Plot the points

$$
A=(-3,2),\qquad B=(4,-1),\qquad C=(0,5),\qquad D=(-2,0),\qquad E=(3,0).
$$

1. State the quadrant of every point that does not lie on an axis.
2. State which points lie on the $x$-axis and which lie on the $y$-axis.
3. Write the coordinates of the reflection of $A$ and $B$ across the $x$-axis.
4. Write the coordinates of the reflection of $A$ and $B$ across the $y$-axis.
5. Write the coordinates of the reflection of $A$ and $B$ across the origin.
6. Mark all reflected points on the same diagram.

<div class="required-record" markdown>

### Required record

Your solution must contain one labelled coordinate diagram and a table with the original and reflected coordinates.

</div>

<div class="verification-box" markdown>

### Verification

For each reflection, state which coordinate changes sign and which coordinate remains unchanged.

</div>
