## Task

Consider the circle

$$
x^2+y^2=9.
$$

1. Find all real values of $y$ corresponding to each of the inputs $x=-3,-2,0,2,3,4.$
2. Record the results in a table.
3. State for which listed values of $x$ there are two outputs, one output or no real output.
4. Plot all obtained points.
5. Explain why the entire circle cannot be described by one function $y=f(x)$.
6. Write formulas for the upper and lower halves of the circle.

<div class="required-record" markdown>

### Required record

Include the completed input-output table, the graph and the two formulas for the semicircles.

</div>

<div class="verification-box" markdown>

### Verification

Substitute one point from the upper half and one point from the lower half into the original circle equation.

</div>
