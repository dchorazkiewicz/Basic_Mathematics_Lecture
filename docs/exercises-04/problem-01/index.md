## Task

Consider the parametrization

$$
P(t)=(3\cos t,3\sin t).
$$

1. Compute $P(t)$ for $t=0,\frac{\pi}{6},\frac{\pi}{2},\pi,\frac{3\pi}{2}$.
2. Record the results in a table with columns $t$, $x(t)$ and $y(t)$.
3. Plot the five points and draw the circle traced by the parametrization.
4. For each computed point, verify the Cartesian equation $x^2+y^2=9$.
5. State the centre and radius of the curve.

<div class="required-record" markdown>

### Required record

Include the parameter table, the drawing and the five substitution checks.

</div>

### Verification
