## Task

Consider the family

$$
P_{h,k,a,b}(t)=(h+a\cos t,k+b\sin t).
$$

Use the parameter sets $(h,k,a,b)=(0,0,4,2)$, $(2,0,4,2)$ and $(0,0,6,1)$.

1. For each family member, compute the points selected by $t=0,\frac{\pi}{2},\pi,\frac{3\pi}{2}$.
2. Draw the three ellipses.
3. Prepare a table with columns: symbol, what it changes, what remains fixed, and geometric interpretation.
4. Explain why changing $t$ does not create a new ellipse, while changing $h,k,a$ or $b$ generally does.
5. Give one example in which two different values of $t$ select the same point because the interval has been extended beyond one full period.
