## Task

Consider

$$
P(t)=(t,t^2-1).
$$

1. Compute $P(t)$ for $t=-2,-1,0,1,2$.
2. Plot the five points and sketch the curve.
3. Eliminate the parameter by expressing $y$ in terms of $x$.
4. Verify every computed point in the resulting Cartesian equation.
5. On the same drawing, mark the part traced when the parameter is restricted to $-1\le t\le2$.

<div class="required-record" markdown>

### Required record

Include the table, the Cartesian equation, the full sketch and the highlighted restricted trace.

</div>

<div class="verification-box" markdown>

### Verification

The endpoints of the restricted trace must agree with the values obtained for $t=-1$ and $t=2$.

</div>
