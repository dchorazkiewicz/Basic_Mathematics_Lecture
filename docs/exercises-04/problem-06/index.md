## Task

Consider the family

$$
\frac{(x-h)^2}{a^2}+\frac{(y-k)^2}{b^2}=1.
$$

Use the four parameter sets

$$
(0,0,3,2),\quad (2,0,3,2),\quad (0,0,5,2),\quad (0,-1,3,4),
$$

where each tuple is $(h,k,a,b)$.

1. For every tuple, determine the centre, width and height.
2. Write the four axis vertices.
3. Draw the four ellipses, using separate diagrams or one clearly labelled diagram.
4. For each change from the first tuple, state which geometric feature changed and which features remained fixed.

### Required record

Include a parameter-effect table, the vertices and the drawings.
