## Task

Let

$$
P(t)=(2\cos t,2\sin t),\qquad 0\le t\le\pi.
$$

1. Compute the points for $t=0,\frac{\pi}{4},\frac{\pi}{2},\frac{3\pi}{4},\pi$.
2. Plot the points and join them by the traced arc.
3. State the Cartesian equation of the complete circle.
4. Add an inequality that distinguishes the traced semicircle from the untraced one.
5. Repeat the description for the interval $\pi\le t\le2\pi$ without recomputing the entire table.

<div class="required-record" markdown>

### Required record

Include the table, both semicircles on one diagram and the Cartesian equation with the appropriate inequality for each interval.

</div>

<div class="verification-box" markdown>

### Verification

Check the signs of $y(t)$ on both parameter intervals and verify the two common endpoints.

</div>
