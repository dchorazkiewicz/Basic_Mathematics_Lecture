## Task

Let

$$
u=(3,-2),\qquad v=(-1,4).
$$

Compute:

1. $u+v$;
2. $u-v$;
3. $v-u$;
4. $2u$;
5. $-3v$;
6. $2u-v$.

Draw $u$, $v$, $u+v$ and $u-v$ from the origin. For $u+v$, also draw the head-to-tail construction.
