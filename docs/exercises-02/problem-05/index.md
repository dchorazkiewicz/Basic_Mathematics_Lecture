## Task

Let

$$
a=(2,1),\quad b=(6,3),\quad c=(-4,-2),\quad d=(1,-2),\quad e=(3,1).
$$

For each pair below, decide whether the vectors are:

- parallel with the same orientation;
- parallel with opposite orientation;
- perpendicular;
- neither parallel nor perpendicular.

Pairs:

1. $a$ and $b$;
2. $a$ and $c$;
3. $a$ and $d$;
4. $a$ and $e$;
5. $b$ and $d$.

Use scalar multiples to test parallelism and the dot product to test perpendicularity.

### Required record

Include a classification table with the scalar-multiple test, dot product and conclusion for every pair.
