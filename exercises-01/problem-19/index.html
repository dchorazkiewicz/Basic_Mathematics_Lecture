Problem 19 — Describing a region by inequalities

Damian Chorążkiewicz

← Exercise set 01 Lecture 01

Problem

Consider the region described simultaneously by

\[ x^2+y^2\le9 \]

and

\[ y\ge1. \]
  1. Draw the circle \(x^2+y^2=9\) and the line \(y=1\).
  2. Find the two points at which the line meets the circle.
  3. Shade precisely the points satisfying both inequalities.
  4. Classify the points $$ (0,0),\quad (0,2),\quad (2,2),\quad (3,1),\quad (-2,1) $$ as belonging or not belonging to the region.
  5. Describe the boundary of the region. Distinguish the circular part from the line-segment part.
  6. State which boundary points satisfy both boundary equations simultaneously.
  7. For each fixed \(y\) with \(1\le y\le3\), describe the possible values of \(x\).
  8. Write a short paragraph explaining why both inequalities are necessary: what larger set would each inequality describe on its own?

Required record

Include a graph with labelled boundary pieces, the intersection calculation, a point-classification table and a written description of the region.

Verification

Every sample point must be tested in both inequalities. The two boundary-intersection points must be checked in both boundary equations.
