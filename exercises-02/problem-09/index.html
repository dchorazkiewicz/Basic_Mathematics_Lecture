Problem 09 — Linear combinations and generated directions

Damian Chorążkiewicz

← Exercise set 02 Lecture 02

Task

Let

\[ a=(2,1),\qquad b=(4,2),\qquad c=(1,-1). \]
  1. Decide which of the vectors \((6,3)\), \((1,0)\) and \((-4,-2)\) can be written as a scalar multiple of \(a\).
  2. Explain why using both \(a\) and \(b\) does not generate any new direction.
  3. Find coefficients \(\alpha,\beta\) such that $$ \alpha a+\beta c=(3,0). $$
  4. Find coefficients representing \((0,3)\) as a combination of \(a\) and \(c\).
  5. Draw \(a\), \(b\), \(c\) and the two reconstructed target vectors.

Required record

Include the scalar-multiple tests, both solved coefficient pairs and one diagram.

Verification

Substitute every computed coefficient pair back into the linear combination.
