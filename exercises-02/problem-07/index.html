Problem 07 — Projection onto a coordinate axis

Damian Chorążkiewicz

← Exercise set 02 Lecture 02

Task

Let

\[ u=(5,-3),\qquad e_1=(1,0),\qquad e_2=(0,1). \]
  1. Compute \(\operatorname{proj}_{e_1}u\).
  2. Compute \(\operatorname{proj}_{e_2}u\).
  3. Verify that $$ u=\operatorname{proj}{e_1}u+\operatorname{proj}u. $$
  4. For each projection, compute the corresponding remainder and verify that it is perpendicular to the target axis.
  5. Draw the decomposition of \(u\) into horizontal and vertical components.

Required record

Include both projection calculations, both perpendicularity checks and one decomposition diagram.

Verification

The two coordinate-axis projections must add exactly to the original vector.
