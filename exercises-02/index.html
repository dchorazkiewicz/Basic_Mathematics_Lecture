Exercise Set 02

The set follows the division intended for the later student workbook:

  • Problems 01–10 — required practice: calculate, draw, reconstruct and verify;
  • Problems 11–20 — developing work: compare representations, explain geometric meaning, design a construction and prepare a concise mathematical note.

Each problem has its own Markdown file. Separate editable solution.md files will be added only in the forkable student workbook.

Problems 01–10 — required practice

Problem 01 — Vectors determined by two points Compute directed changes and draw several representatives of the same free vector.

Problem 02 — Addition, subtraction and scalar multiples Perform elementary vector operations and connect each result with a geometric arrow.

Problem 03 — A chain of translations Follow several consecutive changes and verify the endpoint using one combined vector.

Problem 04 — Length and normalization Compute lengths, construct unit vectors and verify that normalization preserves direction.

Problem 05 — Parallel, opposite and perpendicular directions Classify vector pairs using scalar multiples and dot products.

Problem 06 — Dot product and angle type Use the sign of the dot product to recognize acute, right and obtuse angles.

Problem 07 — Projection onto a coordinate axis Extract horizontal and vertical components and check the perpendicular remainder.

Problem 08 — Projection onto an oblique direction Compute a non-axis projection, reconstruct the original vector and verify orthogonality.

Problem 09 — Linear combinations and generated directions Decide what can be generated from one or two prescribed vectors.

Problem 10 — Coordinates in a nonstandard basis Find basis coordinates with small integer coefficients and reconstruct the vector.

Problems 11–20 — developing work

Problem 11 — One change, many arrows Prepare a documented comparison between a directed segment and a free vector.

Problem 12 — Different routes, the same displacement Compare several paths with the same total change and explain what vector addition retains.

Problem 13 — Reading scalar multiplication geometrically Build a visual catalogue showing how sign and magnitude of a scalar affect a vector.

Problem 14 — The dot product as directional agreement Create and interpret a table connecting relative direction, angle type and dot-product sign.

Problem 15 — Measuring motion along a chosen direction Use projection to separate useful motion from sideways motion in a simple geometric model.

Problem 16 — Projection onto a direction and its opposite Compare vector and scalar projections onto \(v\) and \(-v\) and explain the difference.

Problem 17 — When do two vectors generate the plane? Compare dependent and independent pairs through calculations and diagrams.

Problem 18 — Choosing a basis adapted to a problem Compare two bases and decide which gives the simpler description of selected vectors.

Problem 19 — The vector is fixed; its coordinates change Document one vector in two bases and distinguish the object from its coordinate description.

Problem 20 — A complete note on vector decomposition Combine change, addition, projection and basis coordinates in one verified mathematical document.
