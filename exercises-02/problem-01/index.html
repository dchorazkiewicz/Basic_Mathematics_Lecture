Problem 01 — Vectors determined by two points

Damian Chorążkiewicz

← Exercise set 02 Lecture 02

Task

Let

\[ A=(1,2),\quad B=(5,-1),\quad C=(-2,4),\quad D=(2,1),\quad E=(0,-3). \]
  1. Compute \(\overrightarrow{AB}\), \(\overrightarrow{CD}\) and \(\overrightarrow{EA}\).
  2. Decide which of these directed segments represent the same free vector.
  3. Find a point \(F\) such that \(\overrightarrow{EF}=\overrightarrow{AB}\).
  4. Find a point \(G\) such that \(\overrightarrow{GA}=\overrightarrow{CD}\).
  5. Draw all directed segments on one coordinate diagram.

Required record

Include the coordinate differences, the constructed points \(F\) and \(G\), and one labelled diagram.

Verification

For every pair claimed to represent the same vector, verify that the coordinate differences are identical.
