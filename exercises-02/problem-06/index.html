Problem 06 — Dot product and angle type

Damian Chorążkiewicz

← Exercise set 02 Lecture 02

Task

Let

\[ u=(1,0),\qquad v=(1,1),\qquad w=(-1,1),\qquad z=(-2,-1). \]
  1. Compute \(u\cdot v\), \(u\cdot w\) and \(u\cdot z\).
  2. Use only the sign of each result to classify the angle with \(u\) as acute, right or obtuse.
  3. Compute \(v\cdot w\) and classify the angle between \(v\) and \(w\).
  4. Determine the exact angles in the cases where this can be read from the diagram using familiar directions.
  5. Draw all four vectors from the origin.

Required record

Include a table with the pair, dot product, sign and angle type.

Verification

Compare every classification with the relative position of the vectors in the drawing.
