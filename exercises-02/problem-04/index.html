Problem 04 — Length and normalization

Damian Chorążkiewicz

← Exercise set 02 Lecture 02

Task

For each vector

\[ u=(3,4),\qquad v=(-6,8),\qquad w=(2,-2), \]
  1. compute its length;
  2. find the corresponding unit vector;
  3. verify that the unit vector has length \(1\);
  4. state whether normalization changes the direction, the orientation or only the magnitude;
  5. draw each original vector together with its normalized version from the origin.

Required record

Include a table containing each vector, its length, its unit vector and the verification of unit length.

Verification

For each normalized vector, substitute its coordinates into the length formula and obtain exactly \(1\).
