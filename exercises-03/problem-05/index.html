Problem 05 — Intersection of two lines

Damian Chorążkiewicz

← Exercise set 03 Lecture 03

Task

Let

\[ L_1:\quad y=2x-1 \]

and

\[ L_2:\quad x+y=5. \]
  1. Find the intersection point algebraically.
  2. Check the point in both line equations.
  3. Draw both lines in one coordinate system.
  4. Read the intersection point from the drawing and compare it with the calculated result.
  5. Write a parametric equation for each line.

Required record

Include the algebraic solution, verification in both lines, the graph and both parametric equations.

Verification

The final point must satisfy both original Cartesian equations.
