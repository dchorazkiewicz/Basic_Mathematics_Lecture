# Plany realizacyjne wykładów

Ten katalog zawiera operacyjną warstwę planu kursu. Pliki główne w katalogu `lecture-plan/` opisują narrację matematyczną, natomiast pliki tutaj określają:

- zakres realizowany w pełni podczas wykładu;
- treści rozwijane tylko częściowo;
- treści sygnalizowane i przekazywane do ćwiczeń;
- didaskalia dla strony HTML i prowadzącego;
- minimalny zapis studenta;
- konkretne bloki zadań do przyszłego workbooku.

Wspólne zasady znajdują się w pliku [`../TEACHING_AND_WORKBOOK_MODEL.md`](../TEACHING_AND_WORKBOOK_MODEL.md).
